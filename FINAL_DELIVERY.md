### Golden Rule Validation Flow

```
Calculate Lease
    ↓
Extract: monthlyPayment, MSRP
    ↓
validateGoldenRule(payment, msrp)
    ↓
percentage = (payment / msrp) × 100
    ↓
passed = percentage ≤ 1.5
    ↓
Render badge (pass or fail)
    ↓
If fail: Calculate adjustment suggestions
    ↓
Display modal with strategies
    ↓
User clicks "Apply"
    ↓
Update fields → Recalculate → Re-validate
```

### Trade Optimization Flow

```
Calculate All Vehicles

    ↓

    ↓

    - Calculate value score
    - Analyze scenarios (full/partial/none)

    ↓

    3. Golden rule focus
    ↓
Score each strategy
    ↓
Select best → Generate recommendation
    ↓
Render optimization panel
    ↓
User clicks "Apply"
    ↓
Distribute equity → Update vehicles → Recalculate
```

## 📈 ALGORITHM DETAILS

### Value Score Calculation (0-100)

```javascript
score = 0

// Factor 1: Payment reduction efficiency (0-30 points)
efficiency = (paymentReduction / appliedEquity) × 10000
score += min(30, efficiency)

// Factor 2: Golden rule impact (0-25 points)
if (achieves golden rule): score += 25
else if (already passing): score += 15
else if (improves): score += 10

// Factor 3: Percentage payment reduction (0-25 points)
score += min(25, percentageReduction)

// Factor 4: Vehicle class (0-20 points)
if (MSRP > $60K): score += 20    // Luxury
else if (MSRP > $40K): score += 15  // Mid-range
else: score += 10                 // Economy

return min(100, score)
```

### Strategy Scoring

```javascript
strategyScore = 0

// Total savings component
strategyScore += totalSavings / 100

// Golden rule bonus
if (fixesGoldenRule): strategyScore += fixedCount × 1000

// Simplicity bonus

return strategyScore
```
